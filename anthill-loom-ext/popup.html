  1. Open a terminal in the anthill-loom directory
  2. Start the server: python loom_server.py
  3. The server runs on localhost:7801 and this extension connects automatically.

What does Loom do?

  • Takes raw ChatGPT conversation exports (JSON from Spider)
  • Extracts user/assistant prompt-response pairs
  • Deduplicates and filters out junk (too short, too long, empty)
  • Outputs clean JSONL files ready for fine-tuning in Forge

Pipeline overview

  1. Spider exports ChatGPT conversations to a big JSON file
  2. Loom (this tool) extracts the useful parts:
  • Finds every user-then-assistant message pair
  • Removes duplicates (based on first 200 characters)
  • Filters out pairs that are too short (<5 chars) or too long (>10K chars)
  • Saves clean JSONL ready for Forge to train on

Input format

  • JSON with a top-level "conversations" array
  • Each conversation has a "messages" array with role and content fields
  • This is the format Anthill Spider produces

Output format

  • JSONL (one JSON object per line)
  • Each line: {"prompt": "...", "completion": "...", "title": "..."}
  • Forge picks these up automatically from the datasets/processed/ folder
