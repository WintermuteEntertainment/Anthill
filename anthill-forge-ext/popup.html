First-time setup

  1. Open a terminal in the anthill-forge directory
  2. Install training dependencies (this is a big download — torch alone is ~2.5GB):
    pip install -r requirements.txt
  3. Start the server: python forge_server.py
  4. The server runs on localhost:7800 by default. Click the ⚙ gear icon next to the connection status to point at a remote machine (e.g. http://BigBlackBox:7800).

You must install the dependencies before starting training. The server itself will start without them, but training will fail with ModuleNotFoundError if torch/transformers/peft are missing.

What does Forge do?

  • Fine-tunes large language models (14B-32B+) on your GPU using QLoRA
  • Uses 4-bit quantization so a 32B model fits in 12-16GB VRAM
  • Exports the fine-tuned model as a GGUF for use with llama.cpp / llama-server

Pipeline overview

  1. Spider scrapes ChatGPT conversations to JSON
  2. Loom extracts prompt/response pairs to JSONL
  3. Forge fine-tunes a model on those pairs using QLoRA
  4. The trained model is exported as a GGUF for llama.cpp / any GGUF-compatible runtime

QLoRA in a nutshell

  • The base model is loaded in 4-bit (fits big models in little VRAM)
  • Only small adapter layers are actually trained (~1-2% of weights)
  • After training, adapters are merged back into the full model
  • The merged model is converted to GGUF for local deployment

VRAM requirements

  • 7B model: ~4 GB (fits on most modern GPUs)
  • 14B model: ~8 GB (fits in 12-16GB VRAM)
  • 32B model: ~16 GB (may offload excess to system RAM)
  • System RAM handles any overflow automatically via device_map="auto"
